═══════════════════════════════════════════════════════════════
  PROBLÈMES POTENTIELS & SOLUTIONS
═══════════════════════════════════════════════════════════════

❌ "Erreur 401 - Unauthorized"
   → La clé API est invalide ou manquante
   ✅ Vérifier la clé dans claude_chat_service.dart ligne 13

❌ "Erreur 429 - Too Many Requests"
   → Limite de requêtes atteinte
   ✅ Attendre quelques instants ou upgrade le plan

❌ "Erreur de connexion"
   → Pas de connexion Internet
   ✅ Vérifier la connexion réseau

❌ "Réponse vide"
   → Problème avec le format de la réponse API
   ✅ Vérifier les logs debugPrint

❌ Chat ne s'affiche pas
   → Problème de navigation
   ✅ Vérifier l'import de MentalityChatPage dans main.dart
