# Mentality - Flutter Web

Application web d'évaluation cognitive basée sur les échelles WAIS-IV.

**Version:** Flutter Web (compilée depuis l'app Flutter native)

## 🧠 Caractéristiques

- **12 tests cognitifs WAIS-IV** entièrement implémentés
- **5 indices cognitifs** : ICV, IVS, IRF, IMT, IVT
- **Calcul du QI** avec normes psychométriques
- **IA adaptative** avec Item Response Theory
- **Chat Assistant** propulsé par Claude AI
- **Tests chronométrés** avec discontinuation
- **Interface Material Design 3**

## 🚀 Déploiement

Cette application est compilée depuis Flutter et prête à déployer.

### Sur Cloudflare Pages

1. Connectez ce repository à Cloudflare Pages
2. Build command: *Laisser vide* (déjà compilé)
3. Build output directory: `/`
4. Deploy!
