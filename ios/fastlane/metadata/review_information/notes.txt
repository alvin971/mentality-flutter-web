Mental E.T. est une application de tests cognitifs adaptatifs basée sur le WAIS-IV (Échelles de Wechsler d'Intelligence pour Adultes), standard mondial en évaluation neuropsychologique.

ACCÈS SANS COMPTE :
L'application est entièrement accessible sans authentification.
Depuis l'écran d'accueil, appuyez sur "Commencer une évaluation" pour lancer immédiatement un test.

FONCTIONNALITÉS TESTABLES :
1. Tests cognitifs adaptatifs (12 sous-tests : Matrices, Cubes, Mémoire, Code, Similitudes, etc.)
2. Résultats détaillés : score FSIQ, 5 indices composites, percentiles
3. Export PDF du rapport de résultats
4. Chat IA pour interpréter les résultats (nécessite connexion internet)
5. Historique des sessions précédentes

MICROPHONE :
Le module "Langage Oral" utilise le microphone (optionnel — peut être ignoré sans impact).
Tous les autres tests fonctionnent sans microphone.

DONNÉES ET SÉCURITÉ :
- Toutes les données sont stockées localement sur l'appareil (IndexedDB chiffré AES-256)
- Aucune transmission de données à des serveurs tiers sans consentement explicite
- Conformité RGPD

Application entièrement gratuite.
